## What changed

The `.claude/` shim layout moves from **whole-dir symlinks** to **real directories holding per-item symlinks**, and the legacy `.claude/_alice` convenience symlink is removed (nothing referenced it).

Why: with `.claude/rules`, `.claude/templates`, `.claude/commands`, and `.claude/references` as whole-dir symlinks, any project-specific file an adopter dropped into them physically landed inside `.alice/` — the sync-managed framework payload — where it shows up as an orphan on every `/sync` and risks being caught in future migrations. `skills/` and `agents/` already used per-item symlinks; this release makes all six categories consistent.

The placement rule is now explicit: **framework content lives in `.alice/` (owned by `/sync`); project-specific skills, rules, templates, commands, and agents are real files/dirs created directly in the matching `.claude/*` dir, beside the framework symlinks.** Bootstrap, `template/CLAUDE.md`, and `/sync` all document and preserve this — `/sync` never replaces a real (non-symlink) entry in `.claude/`.

## Automatic actions

Idempotent. Re-running is a no-op once converted.

```bash
set -e

# 1. Remove the legacy convenience symlink — nothing references it.
if [ -L ".claude/_alice" ]; then
  rm ".claude/_alice"
  echo "[removed] .claude/_alice"
fi

# 2. Convert whole-dir symlinks into real dirs of per-file symlinks.
for dir in rules templates commands references; do
  if [ -L ".claude/$dir" ]; then
    rm ".claude/$dir"
    echo "[unlinked] .claude/$dir (was whole-dir symlink)"
  fi
  mkdir -p ".claude/$dir"
  if [ -d ".alice/$dir" ]; then
    for src in ".alice/$dir"/*; do
      [ -f "$src" ] || continue
      name=$(basename "$src")
      dest=".claude/$dir/$name"
      if [ ! -e "$dest" ] && [ ! -L "$dest" ]; then
        ln -s "../../.alice/$dir/$name" "$dest"
        echo "[linked] $dest -> ../../.alice/$dir/$name"
      fi
    done
  fi
done
```

## Manual actions

- [ ] **If you added project-specific content under `.alice/`** (a skill dir in `.alice/skills/`, a rule in `.alice/rules/`, a command in `.alice/commands/`, etc.), move each to the matching `.claude/*` dir as a real file/dir — e.g. `git mv .alice/skills/my-skill .claude/skills/my-skill` (remove any dangling `.claude/skills/my-skill` symlink first). These show up in `/sync`'s orphan list until moved.
- [ ] **If any local scripts, docs, or CLAUDE.md text reference `.claude/_alice/...`**, rewrite them to `.alice/...`.
- [ ] **Update your `CLAUDE.md` repo-layout section** to match the new shim shape (real dirs of per-item symlinks, no `_alice`) — see the upstream `template/CLAUDE.md` for canonical wording. `/sync` never edits `CLAUDE.md` for you.
- [ ] Verify with `ls -la .claude/` — `rules`, `templates`, `commands`, `references`, `skills`, `agents` should all be real directories; their framework entries symlinks into `.alice/`.
