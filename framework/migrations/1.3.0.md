## What changed

Skill runtime state moved from `<repo>/.tmp/` to `<repo>/.alice/mem/`. Two top-level project dirs (`.tmp/` for state, `.alice/` for the framework payload) collapse into one — everything alice-related now lives under `.alice/`. The framework payload itself (rules, templates, commands, skills, agents, bin) stays committed under `.alice/<x>/`; only the new `.alice/mem/` subdir is gitignored.

Affected paths:

| Before                                | After                                          |
|---------------------------------------|------------------------------------------------|
| `.tmp/diana/<run>/`                   | `.alice/mem/diana/<run>/`                      |
| `.tmp/hugh/<run>/`                    | `.alice/mem/hugh/<run>/`                       |
| `.tmp/pr-slicer/<run>/`               | `.alice/mem/pr-slicer/<run>/`                  |
| `.tmp/qa-reports/`                    | `.alice/mem/qa-reports/`                       |
| `.tmp/projects/<slug>/`               | `.alice/mem/projects/<slug>/`                  |
| `.tmp/research/`                      | `.alice/mem/research/`                         |
| `.tmp/security-reports/`              | `.alice/mem/security-reports/`                 |
| `.tmp/greptile/`                      | `.alice/mem/greptile/`                         |
| `.tmp/freeze-dir.txt`                 | `.alice/mem/freeze-dir.txt`                    |
| `.tmp/alice/reviews/`                 | `.alice/mem/reviews/` (drop redundant `alice/`) |
| `.tmp/nsmm/cdp-profile/`              | `.alice/mem/cdp-profile/` (drop `nsmm/`)       |
| `.tmp/alice-sync/`                    | `.alice/mem/alice-sync/`                       |
| `.tmp/plans/`                         | `.alice/mem/plans/`                            |

In-flight diana / hugh / pr-slicer runs are resumable across this migration as long as the auto-action below relocates their state dirs. After the move, `/diana --resume <slug>` / `/hugh --resume <slug>` find the run under the new path and continue.

## Automatic actions

Idempotent. Re-running is safe — every move guards on source-exists + destination-missing.

```bash
set -e
mkdir -p .alice/mem

# Skill run dirs — preserve full subtree, including in-flight worktrees and step markers.
# `alice-sync` is intentionally NOT in this list: the currently-executing `/sync` is
# actively reading from `.tmp/alice-sync/<ts>/` (the old `/sync` from v1.2.0 wrote there).
# Moving it mid-run would break the active session. The next `/sync` invocation runs the
# new sync.md and writes to `.alice/mem/alice-sync/` natively. The manual-actions checklist
# below covers cleaning up the stale `.tmp/alice-sync/` after this sync completes.
for sub in diana hugh pr-slicer qa-reports projects research security-reports greptile plans; do
  if [ -d ".tmp/$sub" ] && [ ! -e ".alice/mem/$sub" ]; then
    mv ".tmp/$sub" ".alice/mem/$sub"
    echo "[migrated] .tmp/$sub -> .alice/mem/$sub"
  fi
done

# Single-file state
if [ -f ".tmp/freeze-dir.txt" ] && [ ! -e ".alice/mem/freeze-dir.txt" ]; then
  mv .tmp/freeze-dir.txt .alice/mem/freeze-dir.txt
  echo "[migrated] .tmp/freeze-dir.txt -> .alice/mem/freeze-dir.txt"
fi

# Reviews — drop redundant alice/ subdir (was .tmp/alice/reviews/, now .alice/mem/reviews/)
if [ -d ".tmp/alice/reviews" ] && [ ! -e ".alice/mem/reviews" ]; then
  mv ".tmp/alice/reviews" ".alice/mem/reviews"
  rmdir ".tmp/alice" 2>/dev/null || true
  echo "[migrated] .tmp/alice/reviews -> .alice/mem/reviews"
fi

# CDP profile — drop nsmm/ subdir (was .tmp/nsmm/cdp-profile/, now .alice/mem/cdp-profile/)
if [ -d ".tmp/nsmm/cdp-profile" ] && [ ! -e ".alice/mem/cdp-profile" ]; then
  mv ".tmp/nsmm/cdp-profile" ".alice/mem/cdp-profile"
  rmdir ".tmp/nsmm" 2>/dev/null || true
  echo "[migrated] .tmp/nsmm/cdp-profile -> .alice/mem/cdp-profile"
fi

# Sweep any remaining unknown subtrees the adopter may have authored under .tmp/,
# EXCEPT `alice-sync` (still in use by the running /sync — see note above).
if [ -d ".tmp" ]; then
  for entry in .tmp/*; do
    [ -e "$entry" ] || continue
    name=$(basename "$entry")
    if [ "$name" = "alice-sync" ]; then
      continue   # leave for manual cleanup after this sync exits
    fi
    if [ ! -e ".alice/mem/$name" ]; then
      mv "$entry" ".alice/mem/$name"
      echo "[migrated unknown] .tmp/$name -> .alice/mem/$name"
    else
      echo "[skipped — destination exists] .tmp/$name (manual review needed)"
    fi
  done
  # .tmp/ won't be empty yet (alice-sync still inside). User removes it after sync exits.
  echo "[note] .tmp/alice-sync/ left in place — running /sync still uses it. Remove .tmp/ manually after sync completes."
fi

# Patch .gitignore — replace .tmp/ entry with .alice/mem/, or append if missing
if [ -f .gitignore ]; then
  if grep -qE '^\.tmp/?$' .gitignore; then
    # Replace the line in place (BSD/GNU sed compatible — write to tmp then move)
    awk '/^\.tmp\/?$/ { print ".alice/mem/"; next } { print }' .gitignore > .gitignore.alice-migrate
    mv .gitignore.alice-migrate .gitignore
    echo "[updated] .gitignore — replaced .tmp/ with .alice/mem/"
  elif ! grep -qE '^\.alice/mem/?$' .gitignore; then
    printf '\n# alice / project-local agent state\n.alice/mem/\n' >> .gitignore
    echo "[updated] .gitignore — appended .alice/mem/"
  fi
else
  printf '# alice / project-local agent state\n.alice/mem/\n' > .gitignore
  echo "[created] .gitignore with .alice/mem/"
fi
```

## Manual actions

- [ ] **After this `/sync` completes**, `.tmp/alice-sync/` is no longer needed. Run `rm -rf .tmp/` to remove the legacy state dir entirely (the new `/sync` runs write to `.alice/mem/alice-sync/` from now on).
- [ ] If the auto-action printed `[skipped — destination exists]` for any path, both old and new locations have content. Inspect both, merge what you want to keep, then `rm -rf` the leftover.
- [ ] If your `.gitignore` had `.tmp/` mentioned in a comment or grouped with other patterns (e.g. `.tmp/ docs/`), the auto-replace may have missed it. Search and replace any remaining `.tmp/` references manually.
- [ ] If you have a CI job, deploy script, or local tooling that references `.tmp/` paths from alice skills (e.g. uploading `.tmp/qa-reports/`), update those paths to `.alice/mem/` too.
- [ ] If you maintain a custom skill that wrote to `.tmp/`, update its SKILL.md to write to `.alice/mem/` instead.
